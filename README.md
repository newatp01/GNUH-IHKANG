# 강정훈 연구 사이트

연구 간호사 휴가 신청/누적 현황, 연구과제 및 이슈, 회의록, 자유게시판을 관리하는 내부 웹사이트입니다.

## 실행 방법 (Windows)

1. Python 3.10 이상을 설치합니다. (https://www.python.org/downloads/ 에서 설치 시 "Add python.exe to PATH" 체크)
2. 이 폴더(nurse_site)를 원하는 위치에 둡니다.
3. 명령 프롬프트(cmd)를 열고 이 폴더로 이동합니다.
   ```
   cd 경로\nurse_site
   ```
4. 필요한 패키지를 설치합니다.
   ```
   pip install -r requirements.txt
   ```
5. 서버를 실행합니다.
   ```
   python app.py
   ```
6. 브라우저에서 다음 주소로 접속합니다.
   ```
   http://127.0.0.1:5050
   ```

서버를 켜둔 컴퓨터가 사무실 같은 네트워크(같은 와이파이/공유기)에 있다면, 팀원들은 그 컴퓨터의 IP 주소로 접속할 수 있습니다. (예: http://192.168.0.5:5050) IP 주소는 명령 프롬프트에서 `ipconfig` 로 확인할 수 있습니다.

사무실 밖에서도 접속해야 한다면, 이 폴더를 그대로 클라우드 서버(예: Render, PythonAnywhere, 자체 서버 등)에 올려서 24시간 켜두는 방식으로 배포할 수 있습니다. 필요하시면 배포도 도와드릴 수 있습니다.

## 로그인 방법

1. 첫 화면에서 사이트 비밀번호를 입력합니다. (팀 내부에서만 공유)
2. 이름을 선택하면 별도 비밀번호 없이 자동으로 로그인됩니다.
   - 선택 가능한 이름: 강정훈(관리자), 김하은, 이혜란
3. 상단의 "사용자 전환"을 누르면 다른 사람 이름으로 다시 로그인할 수 있습니다.

## 기능

- **홈**: 연구 과제 목록과 해결해야 할 이슈를 보여줍니다. 이슈는 등록 시 자동으로 '해결전' 상태가 되며, '해결중' → '해결됨'으로 상태를 바꿀 수 있습니다. 등록할 때 달력에서 해결 기한을 선택할 수 있습니다. '해결됨'으로 바꾸면 홈 목록에서는 사라지고, 상단 메뉴의 '해결된 이슈'에서 계속 확인할 수 있습니다.
- **간호사 휴가신청 현황**: 이번달/다음달 달력에 누가 휴가인지 표시됩니다. 휴가를 등록하면 간호사별 누적 휴가일수(소수점 첫째 자리까지)와 사용 날짜가 자동으로 계산되어 표시됩니다.
- **회의록**: PDF, 워드(doc/docx), 한글(hwp/hwpx) 파일을 업로드할 수 있고, 로그인한 사람은 누구나 다운로드할 수 있습니다.
- **자유게시판**: 자유롭게 글을 올리고 볼 수 있습니다.

## 데이터 저장

모든 데이터는 이 폴더 안의 `data.db` (SQLite 데이터베이스) 파일과 `uploads` 폴더(회의록 파일)에 저장됩니다. 이 폴더를 통째로 백업하면 데이터도 함께 보관됩니다.

## 비밀번호 변경

사이트 비밀번호는 `app.py` 파일 상단의 `SITE_PASSWORD` 값을 수정하면 바뀝니다.

## 실제 도메인(gnuh-kang-ih.org)으로 배포하기

같은 폴더의 `배포가이드.md` 파일에 도메인 구매부터 Render 배포, DNS 연결까지 순서대로 정리해 두었습니다.

## 관리자(강정훈) 로그인

이름 선택 화면에서 "강정훈"을 누르면 별도의 관리자 비밀번호를 입력해야 합니다.
기본 관리자 비밀번호는 `0168` 이며, 필요하면 app.py 상단의 `ADMIN_PASSWORD` 값을 바꾸거나
Render 배포 시 환경변수 `ADMIN_PASSWORD` 를 추가해서 바꿀 수 있습니다.

관리자로 로그인하면 "휴가신청 현황" 페이지에서 "전체 휴가 초기화" 버튼으로 모든 간호사의 휴가 기록을
한번에 삭제할 수 있습니다 (되돌릴 수 없으니 주의해서 사용하세요).

휴가 등록/수정/취소는 김하은, 이혜란 님으로 로그인했을 때만 가능합니다.

## 회의록/이슈/과제 삭제

연구 과제 목록, 이슈(홈 화면 및 해결된 이슈 보관함), 회의록 목록 각 항목 옆에 "삭제" 버튼이 있습니다.
눌러서 확인창에서 확인하면 삭제됩니다 (되돌릴 수 없습니다). 연구 과제를 삭제해도 거기 달려있던
이슈 자체는 남고 과제 태그만 사라집니다.


## 이번 업데이트

- 글자 크기를 이전 대비 75%로 줄였습니다.
- 휴가 등록/수정 화면의 날짜 입력이 브라우저 기본 달력 대신 더 큰 자체 달력으로 바뀌었습니다.
- 예전에 잘못 저장된(종료일이 시작일보다 빠른) 휴가 기록도 화면에서 자동으로 순서를 바로잡아 더 이상 음수로 보이지 않습니다.
- 휴가 누적 현황의 각 기간이 눌러야 하는 버튼(칩) 모양으로 더 명확하게 바뀌었습니다 (김하은, 이혜란 로그인 시).
- 연구 과제마다 여러 파일을 첨부하고 다운로드/삭제할 수 있습니다 (PDF, 워드, 한글, 엑셀, 파워포인트, 이미지, zip 등).


## 연구 과제 카테고리

연구 과제를 등록할 때 SIT, IIT, 관찰&설문연구, 후향적 연구 중 하나를 선택하게 되어 있고,
선택한 분류가 과제 목록에 색깔 있는 배지로 표시됩니다. 이 업데이트를 적용하기 전에 이미
등록해두신 과제들은 분류가 비어 있는 채로 남아있으니, 필요하면 새로 등록하시거나 나중에
분류 수정 기능을 요청해주세요.
